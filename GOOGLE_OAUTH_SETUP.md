## 🔍 How Our Google OAuth Works

### Flow:
1. **Mobile App** → User clicks "Sign in with Google"
2. **Mobile App** → Opens Google Sign-In (using Firebase/Google Sign-In SDK)
3. **Google** → User authenticates and grants permissions
4. **Google** → Returns `id_token` to mobile app
5. **Mobile App** → Sends `id_token` to our backend: `POST /api/v1/auth/google`
6. **Backend** → Verifies `id_token` with Google
7. **Backend** → Creates/updates user in database
8. **Backend** → Returns JWT `access_token` and `refresh_token`
9. **Mobile App** → Stores tokens, uses `access_token` for subsequent requests

### Backend Endpoint:
```
POST /api/v1/auth/google
Content-Type: application/json

{
  "id_token": "eyJhbGciOiJSUzI1NiIsImtpZCI6IjE..."
}

Response:
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "user": {
    "id": "uuid",
    "email": "user@example.com",
    "name": "User Name"
  }
}
```
